# Treinos para iPhone

Aplicativo iOS offline com quatro programas de treino:

- Intermediário — 3x por semana
- Intermediário — 4x por semana
- Homem-Hard — 3x por semana
- Homem-Hard — 4x por semana

O aplicativo mantém semana, dia, exercícios concluídos e pesos localmente no iPhone. Nenhum dado de treino é enviado para um servidor.

## Instalação de desenvolvimento

1. Instale o Xcode pela Mac App Store.
2. Abra `ios/App/App.xcodeproj` no Xcode. Os arquivos offline do app já estão incluídos no projeto.
3. Em **Signing & Capabilities**, escolha sua conta em **Team**.
4. Conecte e selecione o iPhone como destino.
5. Pressione **Run**.

Uma conta Apple gratuita permite testes pessoais no aparelho, mas a assinatura de desenvolvimento precisa ser renovada periodicamente.
